## 🎨 Design & Features

- **Playful Geometric Design System**:

  - Infinite Marquee Ticker and Interactive Filterable Project Matrix.
- **⚡ Planet Namek Super Saiyan Mode**:
  - Dark cataclysmic sky (`#0A1410`) & obsidian cards (`#0F1E17`).

- **⭐ 7 Collectible Dragon Balls & Radar**:
  - Crisp 5-pointed red star SVG geometry inside 34px orbs.

  - Summon Shenron easter egg upon collecting all 7 balls.
- **☁️ Flying Nimbus (Kinto'un)**:

## 💻 Running Locally

No dependencies or build steps required. Simply open `index.html` in any modern web browser or serve it using Live Server / Python:

```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve .
```
